# PayFlow-Sistemas
💳 Sistema Inteligente de Gestão de Pagamentos para Seguradoras

---

📌 Visão Geral

O PayFlow é uma aplicação web desenvolvida com foco em facilitar o controle financeiro no setor de seguros, permitindo a gestão eficiente de clientes, apólices, cobranças e pagamentos.

O sistema foi projetado para oferecer organização, clareza e agilidade auxiliando na tomada de decisões e no acompanhamento de pendências financeiras.

---

✨ Destaques do Projeto

* 📊 Dashboard com indicadores em tempo real
* 💰 Controle completo de cobranças e pagamentos
* 📄 Gestão de apólices e contratos
* 👤 Cadastro e gerenciamento de clientes
* 🔍 Filtros e buscas avançadas
* 📈 Visualização clara de inadimplência

---

 🧠Arquitetura e Conceitos

O projeto foi desenvolvido seguindo o padrão **MVC (Model-View-Controller)**, garantindo:

- Separação de responsabilidades
- Código organizado e escalável
- Facilidade de manutenção

A aplicação segue o modelo cliente-servidor, com comunicação entre front-end e back-end e persistência de dados em banco relacional.

🚀 Como Executar o Projeto

### Pré-requisitos
- PHP 8.x + Composer
- Node.js + NPM/Yarn
- PostgreSQL

### Passo a passo
1. Clone o repositório: `git clone https://github.com/seu-usuario/PayFlow-Sistemas.git`
2. Instale as dependências do Back-end: `composer install`
3. Configure o arquivo `.env` com suas credenciais do banco de dados.
4. Gere a chave da aplicação: `php artisan key:generate`
5. Execute as migrations: `php artisan migrate`
6. Instale as dependências do Front-end: `npm install`
7. Inicie os servidores: `php artisan serve` e `npm run dev`
